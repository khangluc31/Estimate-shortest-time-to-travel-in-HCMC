# Comprehensive Guide: `node_dict` and `graph` Data Structures

This document provides a detailed breakdown of the `node_dict` and `graph` structures generated by [untitled9(1).py](file:///Users/votoan/Downloads/Traffic/untitled9%281%29.py), explaining their internal schemas, real-world meanings, and code examples for using them in pathfinding applications.

---

## 1. Overview

To model spatial traffic routing in Python, the codebase splits the road network into two decoupled data structures:

| Structure | Mathematical Role | Computer Science Structure | Description |
| :--- | :--- | :--- | :--- |
| **`node_dict`** | Vertices ($V$) | Hash Map (`dict`) | Maps junction IDs to spatial Earth coordinates `(long, lat)`. |
| **`graph`** | Weighted Edges ($E$) | Adjacency List (`dict` of `lists`) | Maps start nodes to outgoing road segments with penalized time costs. |

---

## 2. Deep Dive: `node_dict`

### Purpose
Stores the physical geographic location of every intersection or node in the network. Used by heuristic functions to measure straight-line distances.

### Schema & Data Types
* **Type**: `dict[NodeID, tuple[float, float]]`
* **Key**: `_id` (`int` or `str`) — The unique node identifier.
* **Value**: `(longitude, latitude)` (`tuple` of 2 `float`s) — WGS84 decimal coordinates.

### Memory Representation
```python
node_dict = {
    101: (106.68214, 10.76251),  # Intersection 101 at (Longitude, Latitude)
    102: (106.68502, 10.76403),  # Intersection 102
    103: (106.68910, 10.76811),  # Intersection 103
}
```

### How it is Built in Code
```python
nodes = node_data.dropna(subset=['_id', 'long', 'lat'])
node_dict = nodes.set_index('_id')[['long', 'lat']].apply(tuple, axis=1).to_dict()
```

## 3. Deep Dive: `graph`

### Purpose
Represents the road topology. For any given node, it provides all connected destination nodes along with the physical distance and traffic-adjusted travel time.

### Schema & Data Types
* **Type**: `dict[NodeID, list[dict]]`
* **Key**: `s_node_id` (`int` or `str`) — The starting node/intersection ID.
* **Value**: `list[dict]` — List of outgoing road edges.
  * `target`: `e_node_id` (`int` or `str`) — Destination node ID.
  * `travel_time`: `float` — Cost in **seconds**, factoring in physical length, speed limit, traffic velocity, Level of Service (LOS) penalty, and road type penalty.
  * `length`: `float` — Physical segment length in **meters**.
  * `street_name`: `str` — Name of the road/street.

### Memory Representation
```python
graph = {
    101: [
        # Outgoing Road 1 (to Node 102)
        {
            'target': 102,
            'travel_time': 35.4,       # Travel time in seconds (with traffic penalties)
            'length': 450.0,           # Distance in meters
            'street_name': 'Nguyen Trai'
        },
        # Outgoing Road 2 (to Node 103)
        {
            'target': 103,
            'travel_time': 62.1,
            'length': 800.0,
            'street_name': 'Tran Hung Dao'
        }
    ],
    
    102: [ ... outgoing edges from Node 102 ... ]
}
```

### How it is Built in Code
```python
from collections import defaultdict

graph = defaultdict(list)
for x in edges_v1.itertuples(index=False):
    graph[x.s_node_id].append({
        'target': x.e_node_id,
        'travel_time': x.travel_time,
        'length': x.length,
        'street_name': x.street_name
    })
graph = dict(graph)
```

### Example 2: Calculate Straight-Line Distance Between Two Nodes
Using `node_dict` to calculate the spatial distance between Node 101 and Node 103:

```python
import math

def get_node_distance(node_a, node_b, node_dict):
    lon1, lat1 = node_dict[node_a]
    lon2, lat2 = node_dict[node_b]
    
    R = 6371000.0  # Earth radius in meters
    phi1, phi2 = math.radians(lat1), math.radians(lat2)
    dphi = math.radians(lat2 - lat1)
    dlambda = math.radians(lon2 - lon1)
    
    a = math.sin(dphi / 2.0)**2 + math.cos(phi1) * math.cos(phi2) * math.sin(dlambda / 2.0)**2
    return 2.0 * R * math.atan2(math.sqrt(a), math.sqrt(1.0 - a))

distance_meters = get_node_distance(101, 103, node_dict)
print(f"Straight-line distance between Node 101 and 103: {distance_meters:.2f} meters")
```

### Example 3: Find the Fastest Outgoing Road from an Intersection
Using `graph` to inspect edges and find the route with the minimum `travel_time`:

```python
def find_fastest_outgoing_road(start_node, graph):
    neighbors = graph.get(start_node, [])
    if not neighbors:
        return None
        
    # Find edge with smallest travel_time
    fastest_edge = min(neighbors, key=lambda x: x['travel_time'])
    return fastest_edge

fastest = find_fastest_outgoing_road(101, graph)
print(f"Fastest road from 101 is {fastest['street_name']} to Node {fastest['target']} taking {fastest['travel_time']:.1f} seconds.")
```

### Example 4: Calculate Total Time and Distance for a Specific Path
Given a sequence of nodes (a route), compute total driving time and physical distance:

```python
def evaluate_route(path_nodes, graph):
    total_time = 0.0
    total_distance = 0.0
    
    for i in range(len(path_nodes) - 1):
        u = path_nodes[i]
        v = path_nodes[i + 1]
        
        # Look up edge from u to v in graph
        edges = graph.get(u, [])
        match = next((edge for edge in edges if edge['target'] == v), None)
        
        if match:
            total_time += match['travel_time']
            total_distance += match['length']
        else:
            print(f"Warning: No direct edge between {u} and {v}")
            
    return total_time, total_distance

path = [101, 102, 105, 109]
time_sec, dist_m = evaluate_route(path, graph)
print(f"Route {path}: Total Time = {time_sec / 60:.2f} mins, Total Distance = {dist_m / 1000:.2f} km")
```

### Example 5: Heuristic A* Pathfinding Query
Using `graph` for step costs $g(n)$ and `node_dict` for heuristic estimates $h(n)$:

```python
import heapq

def run_a_star(start_node, goal_node, graph, node_dict, v_max):
    open_set = []
    # heapq format: (f_score, current_node)
    heapq.heappush(open_set, (0.0, start_node))
    
    g_score = {start_node: 0.0}
    came_from = {}
    
    while open_set:
        _, current = heapq.heappop(open_set)
        
        if current == goal_node:
            # Reconstruct path
            path = []
            while current in came_from:
                path.append(current)
                current = came_from[current]
            path.append(start_node)
            return path[::-1], g_score[goal_node]
            
        # 1. Query graph for neighbors
        for edge in graph.get(current, []):
            neighbor = edge['target']
            tentative_g = g_score[current] + edge['travel_time']
            
            if neighbor not in g_score or tentative_g < g_score[neighbor]:
                came_from[neighbor] = current
                g_score[neighbor] = tentative_g
                
                # 2. Query node_dict for heuristic calculation
                dist = get_node_distance(neighbor, goal_node, node_dict)
                h_score = dist / v_max
                
                f_score = tentative_g + h_score
                heapq.heappush(open_set, (f_score, neighbor))
                
    return None, float('inf')
```
